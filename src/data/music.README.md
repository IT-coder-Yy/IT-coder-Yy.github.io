## 替换正式歌单

1. 准备可用于网站公开播放的音频或官方公开音源链接、UTF-8 LRC 歌词和封面；本站文件放到 `public/music/`。
2. 更新 `musicTracks` 中的 `id`、`title`、`artist`、`audio`、`lyrics`、`cover`；正式歌曲移除 `demo: true`。
3. 站内资源路径使用 `sitePath('/music/文件名.mp3')`，兼容 GitHub Pages 子路径。文件名与大小写必须匹配。
4. 新歌使用新的 `id`；调整同一首歌的顺序保留 `id`，访客进度不会因排序而串歌。
5. 对照实际音频版本试听开头、中段、结尾，检查歌词时间，运行 `npm run build` 后重新部署。

支持标准逐句 LRC，包括多时间戳和 `[offset:毫秒]`。播放器将歌词当纯文本渲染。专有 KRC 歌词文件不能直接替代 LRC。优先使用同站资源；外部歌词 URL 需要允许跨域读取。

本地 KRC 可用 `node src/fixtures/convert-krc.mjs "输入.krc" "public/music/输出.lrc"` 转换；脚本保留原时间，不会自动校正音频版本，且不会覆盖已有输出文件。不要用文件名相同来代替版本和时间轴检查。

## 行为与验证

- 首次访问保持安静，不预加载音频；默认音量 25%。刷新后恢复曲目、进度和音量，点击才续播。
- 中文／英文首页、详情、博客之间使用 Astro ClientRouter 与持久播放元素；普通站内前进／后退保持播放。完整刷新、关闭页面、离站跳转会终止当前页面的播放。
- 项目预览收起播放器面板，预览顶部保留暂停／继续。切换浏览器标签不主动暂停。
- 单曲失败跳过；一轮全部失败停止，点击播放重试。歌词失败不影响音频，提供独立重试。
- 键盘可操作按钮、进度、音量、歌词和歌单；展开时聚焦播放按钮，打开歌单会聚焦并滚动到当前歌曲，方向键调节滑块。Escape 优先关闭歌单／音量弹层并返回对应按钮，再按一次收起播放器。
